# ⚽ LS 點球大戰（Penalty Shootout）

LS 特輯系列的**獨立小遊戲**：站在五人制球門前罰點球，拖曳瞄準、放開射門，跟會撲救的守門員對決。

🌐 **線上玩**：https://aibotchao-cell.github.io/penalty-shootout/

---

## 🎮 怎麼玩

| 平台 | 操作 |
|---|---|
| 🖥 電腦 | 移動滑鼠瞄準 · **點一下射門** |
| 📱 iPad／手機 | **拖曳瞄準、放開射門**（也可以按右下角的「射門」大按鈕） |

- **5 球決勝**，踢完顯示成績與最高紀錄
- 踢**角落**（貼近門柱、上方）最難被撲到；一直踢**中間**會被守門員擋下
- 進球有歡呼音效、被撲到有嘆息音效（Web Audio 即時合成，不需要音檔）

## 🎚 難度（開始畫面可選）

| 難度 | 中間射門被撲 | 角落射門被撲 | 說明 |
|---|---|---|---|
| 😊 簡單 | 約 17% | 約 10% | 守門員動作慢、常判斷錯 |
| ⚽ 普通 | 約 48% | 約 27% | 會猜方向，踢角落比較容易進 |
| 😤 困難 | 約 68% | 約 40% | 反應快、判斷準，要踢很角落才有機會 |

> 守門員**一定會有反應**：每次射門他都會往球的方向撲過去，只是「判斷誤差」依難度不同（不會站著看球滾過去）。

## 🌟 超級巨星（用錢買）

- 一開始是 **梅西（10 號）**，不用錢
- **每完成一輪就賺錢**：每進一球 **+100 元**、完成一輪再 **+50 元**，難度加倍（簡單 ×1／普通 ×1.5／困難 ×2）
- 用賺到的錢買超級巨星：

| 球員 | 號碼 | 價格 |
|---|---|---|
| 梅西 | 10 | 免費（一開始就有） |
| C羅 | 7 | 💰 500 |
| 姆巴佩 | 10 | 💰 900 |

| 哈蘭德 | 9 | 💰 2000 |

- 錢夠的球員會**亮綠框**（可以直接買）；不夠的會顯示還差多少
- 你選的球員會顯示在畫面上方的 HUD（例如 `C羅 7`），**不會站在場上擋住視角**
- 錢、已買球員、最高紀錄都存在瀏覽器（localStorage），下次打開還在

## 🛠 技術

- Three.js（`vendor/three.module.js`），純靜態網站，免伺服器
- 場景沿用 LS 特輯的五人制球場：綠茵草皮＋白線＋鐵網＋LS 隊徽＋黑白五角球
- 音效全部用 Web Audio 即時合成（`js/sfx.js`）
- 本機測試：`python serve.py`（埠 **8200**，與足球 8100、槍戰 8000 可同時開）

## 📁 檔案

```

js/sfx.js           音效合成（叫聲／踢球／歡呼／嘆息）
js/version.js       版本號（由 release.py 更新）
assets/logo.png     LS 隊徽
release.py          發版工具（版本號＋CHANGELOG＋差異檔＋git tag）
serve.py            本機測試伺服器（no-cache，支援 IPv4/IPv6）
```
